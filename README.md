# star-clip

KiCad files for a PCB hair clip I designed. I thought this would be a cute 'woman-in-STEM' accessory.
What it is: a star-shaped clip with 6 LEDs that blink, driven by a 555 timer
and powered by ecoin cell batteries

## BOM

| Part | Value | Quantity |
|------|-------|----------|
| Coin cell battery holder (Keystone 3034, 20mm) | | 2 |
| Electrolytic capacitor (8mm radial) | (e.g. 10µF) | 2 |
| 5mm LED | | 6 |
| 2N3906 PNP transistor | | 2 |
| Resistor | 470Ω | 6 |
| Resistor | 4.7kΩ | 1 |
| Resistor | 47kΩ | 3 |
| LM555 timer (DIP-8) | | 1 |
